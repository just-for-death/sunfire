# Sunfire v11.0.0-beta Release Notes

## Overview
**Sunfire v11.0.0-beta** (`11.0.0-beta+32`) follows GitHub **v10.0.0-beta** with FOSS/privacy hardening, complete sync & tracker wiring, practical online/offline tests against live Suwayomi, Android volume-key reading, and **bundled FOSS extension icons** (no Google Favicon CDN).

This Codemagic build also includes the post-v11 tracker GraphQL fix and tablet sidebar overflow fix.

---

## Changelog since v10.0.0-beta

### FOSS extension icons
- Bundled `assets/icons/sources/*.png` for every shipped JS extension
- `SourceIconHelper` + `SourceIconImage` resolve `asset:` URIs and letter fallbacks
- Google Favicon CDN removed from runtime fallbacks and bundled metadata
- Browse Sources / Extensions / Migrate tiles render asset icons offline

### Sync & trackers
- Offline queue for category create / rename / delete / manga category assign
- Library batch category moves use `SyncEngine` (replay when back online)
- Reader pushes tracker progress when a chapter first becomes read
- **`trackProgress` now sends only `mangaId`**, matching Suwayomi `TrackProgressInput` (MAL/AniList/etc. no longer fail with `trackerId` WrongType)
- Score, status, and dates still use `updateTrack` from the tracking sheet
- GraphQL HTTP 4xx no longer marks the whole server offline
- Legacy download prefs aliased to live settings (`autoDownloadWhileReading`, etc.)

### Reader, Android, iOS
- Volume-key page turns on **Android** as well as iOS/macOS
- Cleartext limited to loopback / emulator hosts
- Unused `FOREGROUND_SERVICE*` permissions removed
- Cover disk cache hash write/read consistency fix

### Tablet / iPad sidebar
- Collapse/expand no longer overflows the header `Row` (~46px yellow/black stripes in debug)
- Labels and header use actual rail width during the animation (≥180px)

### iOS CI (Codemagic)
- Swift Package Manager disabled for this app: plugins still on CocoaPods (`isar`, `flutter_qjs`, `flutter_secure_storage`, `fluttertoast`, `cupertino_http`, `permission_handler_apple`)
- Builds keep using CocoaPods until those plugins ship `Package.swift`

### Tests
- `practical_online_offline_flow_test.dart` (dead-port offline + Docker Suwayomi `:4567` live)
- `beta_v11_features_test.dart` plus sidebar collapse/expand overflow coverage
