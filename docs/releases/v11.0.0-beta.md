# Sunfire v11.0.0-beta Release Notes

## Overview
**Sunfire v11.0.0-beta** (`11.0.0-beta+32`) builds on GitHub’s latest **v10.0.0-beta** with FOSS/privacy hardening, sync & tracker completeness, practical online/offline test coverage against live Suwayomi, Android volume-key reading, and **bundled FOSS extension icons** (no Google Favicon CDN).

---

## Major Changes

### 1. FOSS extension icons (new)
- Bundled `assets/icons/sources/*.png` for every shipped JS extension
- `SourceIconHelper` + `SourceIconImage` resolve `asset:` URIs and letter fallbacks
- Google Favicon CDN removed from runtime fallbacks and bundled metadata
- Browse Sources / Extensions / Migrate tiles render asset icons offline

### 2. Sync & tracker wiring
- Offline queue for category create / rename / delete / manga category assign
- Library batch category moves use `SyncEngine` (replay when back online)
- Reader pushes tracker progress via `syncMangaTrackerProgress` when a chapter first becomes read
- Legacy download prefs aliased to live settings (`autoDownloadWhileReading`, etc.)

### 3. Privacy / Android FOSS polish
- Cleartext limited to loopback / emulator hosts in `network_security_config.xml`
- Unused `FOREGROUND_SERVICE*` permissions removed; boot receiver kept for WorkManager
- Cover disk cache hash write/read consistency fix

### 4. Reader & platform
- Volume-key page turns on **Android** as well as iOS/macOS
- Per-manga reading mode, library Last Read, Updates filters, and related Sprint A–C polish from the post-v10 audit retained under this release

### 5. Tests
- New `practical_online_offline_flow_test.dart` (dead-port offline + Docker Suwayomi `:4567` live)
- Live Suwayomi tests use proper skips; offline tests no longer assume `:4567` is down
- Shared QuickJS native loader (`test/support/quickjs_test_loader.dart`) survives `flutter clean` rebuilds
- New `beta_v11_features_test.dart` for version/icon/sync coverage
