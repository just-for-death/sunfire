## 🚀 Sunfire v5.0.0 Beta

### ⚙️ Complete Suwayomi Server & Settings Overhaul
- **10 Dedicated Settings Sections**: Complete parity with Suwayomi server capabilities across 10 modular subpages:
  - **Server Settings**: Server host, port, SSL toggle, Basic Authentication (username & password), WebSocket status, connectivity test, and FlareSolverr proxy.
  - **Library Settings**: Default categories, auto-update frequencies, unread/download badges, cover aspect ratio presets, and column sizing.
  - **Reader Settings**: Default reading modes (Webtoon, LTR, RTL, Continuous Vertical/Horizontal), inverted tap zones, volume key navigation, keep screen awake, and dual-page split mode for tablets.
  - **Download Settings**: Concurrent download slots, auto-download next unread chapters, cache clearing, download location management, and network constraints (Wi-Fi only).
  - **Browse & Sources Settings**: Extension repos, language filtering, NSFW source toggles, source pinning, and cache controls.
  - **Backup & Restore**: Suwayomi server-side backup creation, automatic local backup schedules, and backup restore workflows.
  - **Appearance Settings**: Theme modes (Dark, Light, AMOLED black, System OLED), accent color palettes, and glassmorphism intensity controls.
  - **Tracking Settings**: Tracker synchronization (AniList, MyAnimeList, Kitsu, Shikimori, Bangumi).
  - **Advanced Settings**: Cache purges, QuickJS engine garbage collection, network inspection, database compacting, and raw diagnostics.
  - **Extension Repos**: Custom third-party Tachiyomi/Keiyoushi extension repository management.
- **Global Settings Search**: Instant fuzzy and keyword search across all settings options, categories, and switches with direct navigation to the target item.

---

### 🌐 Dynamic FlareSolverr & Zero Admin Hardcoding
- **Configurable FlareSolverr Proxy**: Completely eliminated all hardcoded developer/mesh IP addresses. Users can now freely input their FlareSolverr proxy address (e.g., local server, Tailscale, Docker) during the initial **Onboarding Setup** or at any time in **Settings > Server**.
- **Integrated Headless Fallback**: When FlareSolverr is unreachable or unconfigured, Sunfire gracefully and transparently falls back to the in-app headless/in-place WebView solver.
- **Suwayomi Authentication Hardening**: Implemented compliant RFC 7617 HTTP Basic Authentication with dynamic Base64 credentials injection across all GraphQL queries, REST image endpoints, and WebSocket subscriptions.

---

### 🎨 Android UI/UX & Responsive Layout Polish
- **SunfireBadge Component**: Replaced awkward chip styles and oversized badges with cohesive, responsive, auto-scaling `SunfireBadge` pills across manga detail tags, status indicators, and chapter cards.
- **Text Wrap & Overflow Defense**: Resolved all title and badge overlaps in manga headers, download queues, and settings headers across small phone screens and ultra-wide foldables.
- **Enhanced Safe Area Insets**: Handled edge-to-edge notches, LiveContainer dynamic status bar heights (54dp), and gesture bars without clipping action buttons or search bars.
- **Tablet / Large-Screen Experience**: Adaptive two-pane detail layout and liquid glass navigation rail for tablets and foldables.

---

### ⚡ Engine & Self-Healing Reliability
- **Multi-Pass Image Healing**: Resilient multi-tier self-healing image resolver with automatic Referer stripping, desktop user-agent spoofing, and Cloudflare clearance cookie forwarding.
- **Download Queue Auto-Resume**: Seamless lifecycle auto-resume for interrupted downloads across app suspension and network transitions.
