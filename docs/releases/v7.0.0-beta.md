## 🚀 Sunfire v7.0.0 Beta

### ⚡ Full System & UI Audit — Complete Setting & Lifecycle Wiring
- **Multi-Screen Lifecycle Synchronization**: Fixed asynchronous tab index listening across Library, Updates, and History so unread badges, history records, and manga covers update instantaneously upon tab switching.
- **Customizable Default Launch Screen**: Choose your preferred entry view (*Library*, *Updates*, *History*, or *Browse*) via **Settings ➔ General ➔ Start Screen**.
- **Accidental Exit Protection**: Optional **Confirm Exit** dialog on root back gestures preventing unwanted application terminations.
- **Dynamic Network & Scraper Timeouts**: JS scrapers, FlareSolverr bypasses, and image transports now respect user-defined network timeout preferences (10s – 120s).
- **Manga Detail Preference Preservation**: Chapter sort order (ascending/descending) preference is reliably saved and restored across sessions.

---

### 📖 Hands-Free Auto-Scroll & Reader Upgrades
- **Expanded Auto-Scroll Range**: Continuous scrolling now reaches up to **1,000 px/s** with fine-grained slider steps (+10, +25, +50 px/s) and one-tap preset jumping.
- **Instant Speed Presets**: Six quick speed presets (*Slow 25*, *Normal 50*, *Fast 120*, *⚡ Faster 250*, *🚀 Turbo 500*, *💨 Hyper 800 px/s*).
- **Save As Default Action**: In-reader speed bottom sheet now features a direct **Save Default** button to persist tuned reading speeds globally.
- **Unified Color Filters**: Calibrated *Sepia*, *Amber Night*, *Grayscale*, and *Invert Colors* filters synchronized across the reader HUD and Reader Settings.
- **Boundaries & Reading Progress Guard**: Clamped chapter reading progression to prevent `Page 11/10` overflow while suppressing unread badges on fully completed chapters.

---

### 🎨 Clean Settings Organization & Library Controls
- **Dedicated General Settings**: Separated everyday client options (App Language, Date Format, Start Screen, Confirm Exit, Incognito Mode, Network Timeouts, Cache Cleansing) from Developer Diagnostics.
- **Library Category & Badge Toggles**: Toggle **Show Downloaded Badges**, **Show Unread Badges**, and **Show Category Tabs** directly from **Settings ➔ Library**.
- **NSFW Content Preference**: Toggle adult/18+ content filtering across all installed JS scrapers, Keiyoushi APKs, and Suwayomi server extensions.

---

### 🖼️ Self-Healing Image Transports & Published Dates
- **Direct CDN Thumbnails**: Proactive resolution of direct CDN covers for sources like ReadComicsOnline without hitting upstream 403/500 proxy endpoints.
- **Authentic Published Dates**: Direct extraction of authentic publication dates from extension scrapers (*Webtoons*, *WeebCentral*, *MangaHere*, *MangaFreak*), replacing lossy relative timestamps.

---

### 📦 Artifacts in this Release
- `Sunfire-v7.0.0-beta-universal.apk`: Universal Android package supporting all architectures (`arm64-v8a`, `armeabi-v7a`, `x86_64`).
- `Sunfire-v7.0.0-beta-arm64-v8a.apk`: Optimized Android APK for modern 64-bit ARM devices.
- `Sunfire-v7.0.0-beta-armeabi-v7a.apk`: Optimized Android APK for 32-bit ARM legacy devices.
- `Sunfire-v7.0.0-beta-x86_64.apk`: Optimized Android APK for x86_64 emulators and Chromebooks.
- `Sunfire-v7.0.0-beta.ipa`: Unsigned sideload iOS/iPadOS IPA (ready for AltStore, TrollStore, Sideloadly, LiveContainer, Scarlet, Esign).

### 🛠️ Building the New APKs & IPA

#### Local Android Build:
```bash
# Universal APK:
flutter build apk --release --android-skip-build-dependency-validation

# Architecture-Specific Split APKs:
flutter build apk --release --split-per-abi --android-skip-build-dependency-validation
```

#### Local iOS / iPadOS IPA Build:
```bash
# Build xcarchive:
flutter build ipa --release --no-codesign

# Package Unsigned IPA for Sideloading:
mkdir -p build/ios/ipa/Payload
cp -R build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app build/ios/ipa/Payload/
cd build/ios/ipa && zip -qr Sunfire-v7.0.0-beta.ipa Payload
```
