# Sunfire v8.0.0-beta Release Notes

## 🚀 Overview
**Sunfire v8.0.0-beta** delivers a comprehensive system audit and hardening across the reader, navigation controllers, and extension scraper engines. All extension versions are now synchronized across both Sunfire and the Mangayomi Extensions ecosystem, and navigation boundaries are safeguarded against unhandled pop exceptions.

---

## 🔑 Highlights & Key Improvements

### 1. 🛡️ Hardened Navigation Pop Boundaries
- Replaced unhandled `context.pop()` calls across standalone screens (`Download Manager`, `Statistics`, `Source Manga Grid`, `Reader`, and `SettingsSubpageScaffold`).
- Integrated graceful fallback routing (`context.canPop() -> Navigator.canPop() -> context.go('/library' or '/more' or '/browse')`).
- Completely eliminated `GoError: There is nothing to pop` exceptions when navigating from notifications, widgets, deep links, or keyboard escape shortcuts.

### 2. 🔄 Full Extension Version Synchronization
- Synchronized version metadata for `mangago.js` (`1.3.1`), `nhentai.js` (`1.1.1`), and `ninehentai.js` (`1.1.1`) between bundled code and `index.json`.
- Resolves false "Update Available" badges in the Browse tab.
- Bundled extensions in Sunfire and repo extensions in `mangayomi-extensions` are 100% byte-for-byte identical.

### 3. 📅 Authentic Published Dates for Single-Issue Galleries
- Extracted and populated authentic publication dates (`dateUpload`) for `nHentai` and `NineHentai` single-issue chapters, preserving the exact release timestamp without coercion.

### 4. ⚙️ Complete Settings & Reader Experience
- Retained the dedicated General Settings subpage, configurable start screen (`Library`, `Updates`, `History`, `Browse`), exit confirmation toggle, dynamic scraper network timeouts, and hands-free auto-scroll speed controls (up to 1,000 px/s with turbo preset jump).
