# Sunfire v8.0.0-beta Release Notes

## 🚀 Overview
**Sunfire v8.0.0-beta** is a major milestone release delivering Mihon-parity automated library updates with native OS notifications, an ultra-smooth Vsync-synchronized auto-scroll engine for Webtoon / Long-Strip reading modes, a modern frosted-glass floating HUD, full extension synchronization, hardened navigation boundaries, and deep platform stability audits.

---

## 🔑 Highlights & Key Improvements

### 1. 🔔 Automated Library Updates & New Chapter Notifications (Mihon Parity)
- **Unified Chapter Delta Engine**: Automatically snapshots existing chapters before an update and computes exact diffs across both the live Suwayomi Server (`100.71.46.98:4567`) and standalone local QuickJS scrapers.
- **Native OS Notifications**: Dispatches high-priority system alerts with intelligent summaries:
  - *Single Chapter*: Displays `New Chapter: [Manga Title]` with chapter name.
  - *Single Manga (Multiple Chapters)*: Displays `[N] new chapters are now available`.
  - *Multiple Series*: Aggregates title summaries (e.g. `[Manga 1], [Manga 2] and [X] more have updated`).
- **Deep-Linked Notification Actions**: Tapping any update alert navigates directly to the Updates tab.
- **Mihon Scheduling Preferences**:
  - Configurable update intervals: Disabled, 1h, 6h, 12h, 24h, 48h, 72h, or Weekly.
  - Network constraints: *Only on Wi-Fi* (with automatic Tailscale/WireGuard VPN and Ethernet pass-through).
  - Power constraints: *Only While Charging*.
- **Live Progress & Status**: Real-time server update job polling (`runningJobs`, `pendingJobs`) displayed across both Library Settings and the Updates screen.

### 2. ⚡ Fluid Vsync Webtoon Auto-Scroll Engine (60/90/120Hz Parity)
- **Native Vsync Ticker**: Replaced fixed periodic timers with Flutter's native `TickerProviderStateMixin.createTicker`, synchronizing frame execution directly to display hardware refresh rates (60Hz, 90Hz, 120Hz ProMotion/Smooth Display).
- **Frame-Rate Invariant Displacement**: Uses microsecond delta timing (`safeDt = dt.clamp(0.0, 0.05)`) ensuring displacement per second is strictly identical regardless of device frame rate.
- **Smooth Ease-In Ramp**: Gradually accelerates scroll velocity from `0.15` to `1.0` over 400ms (`Curves.easeOutCubic`), eliminating sudden jerky motion when starting or resuming.
- **Intelligent Touch Coordination**: Screen touches instantly pause scrolling, keeping the Vsync timeline aligned so that releasing your finger resumes scrolling smoothly without jumping.
- **Desktop Keyboard Shortcuts**:
  - `S`: Instant auto-scroll toggle on/off.
  - `+` / `=`: Increase speed (+10 px/s).
  - `-`: Decrease speed (-10 px/s).

### 3. 🎨 Frosted-Glass Floating HUD & Interactive Settings
- **Backdrop Blur Pill**: Compact floating pill with Gaussian blur (`BackdropFilter(sigmaX: 12, sigmaY: 12)`).
- **Collapsible Mini-Pill**: Shrinks down to an unobtrusive 32px pill with one tap so it never blocks webtoon artwork.
- **TURBO Accelerator**: Instantly jumps to 500 px/s for rapid skimming.
- **Live Preview Viewport**: `ReaderSettingsScreen` now features a simulated scrolling webtoon preview window that reacts live to slider and preset changes.
- **Quick Preset Chips**: Slow (25 px/s), Normal (50 px/s), Fast (120 px/s), Faster (250 px/s), Turbo (500 px/s), Hyper (800 px/s).

### 4. 🛡️ System Audit, Hardened Pop Boundaries & Extension Sync
- **Hardened Navigation Pop Boundaries**: Replaced unhandled `context.pop()` calls across standalone screens (`Download Manager`, `Statistics`, `Source Manga Grid`, `Reader`, and `SettingsSubpageScaffold`) with fallback routing (`context.canPop() -> Navigator.canPop() -> context.go(...)`), preventing unhandled `GoError` exceptions.
- **Extension Version Synchronization**: Synchronized version metadata for `mangago.js` (`1.3.1`), `nhentai.js` (`1.1.1`), and `ninehentai.js` (`1.1.1`) between bundled code and index metadata, eliminating false update badges.
- **Authentic Publication Dates**: Populated authentic upload dates for `nHentai` and `NineHentai` single-issue chapters, preserving the exact release timestamp without coercion.
- **Android WorkManager Dynamic Rescheduling**: Updating interval or network preferences in settings automatically reconfigures Android WorkManager in the background.
