## 🚀 Sunfire v3.0.0 Beta

### 📱 Modern iPadOS & Tablet Navigation Overhaul (iPadOS 18 - 27.0 HIG)
- **Collapsible Liquid Glass Sidebar**: Replaced the rigid 104px sidebar with an authentic Apple-inspired floating navigation system featuring ultra-thin glassmorphism blur (`BackdropFilter` sigma: 30, `rgba(19, 19, 26, 0.95)`).
- **Smooth Dual Mode (250px ↔ 76px)**: Smooth cubic animation between full expanded sidebar and compact rail mode, with user preference persisted in local storage (`tabletSidebarExpanded`).
- **Apple HIG Action Items**: Clean 44px touch targets with icons, 13.5px typography, subtle glowing pill backgrounds, and right-aligned selection indicators. In compact mode, items transition to centered 46x46 squircle capsules with tooltips.
- **Quick Links & Activity**: Direct one-tap navigation to the Downloads Queue (with dynamic badge indicator for active background downloads) and Reading Stats.
- **Frosted Glass Server Status Card**: Bottom-docked connectivity card displaying live Suwayomi server status or Standalone QuickJS mode, host URL, pulsing connection indicator dot, and a 1-tap 360° spinning sync button.
- **Zero Collision Safe-Area Alignment**: Corrected `SafeArea` insets and removed redundant double-padding so the sidebar header and page titles align horizontally at ~50px without status bar collisions.

---

### 📥 iOS / iPadOS Offline Download & Storage Hardening
- **Dynamic Sandbox Path Resolution**: Resolves app document directories dynamically at runtime via `ContentResolverService` and `DownloadManagerService` instead of hardcoding absolute paths in Isar, preventing broken file paths across iOS container UUID rotations.
- **Apple Files App & OS Artifact Defense**: Filters out `.DS_Store` and hidden metadata files created by macOS Finder and the iOS Files app (`UIFileSharingEnabled: true`); strictly validates image file extensions (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.bmp`).
- **Lifecycle Auto-Resume**: Auto-recovers the local download queue in `didChangeAppLifecycleState(AppLifecycleState.resumed)` as soon as the user returns from iOS app suspension.
- **Cloudflare & Anti-Bot Cookie Forwarding**: Automatically forwards Cloudflare clearance cookies (`MClient.getCookiesPref(pageUrl)`) and user-agent headers into offline page downloads.
- **Self-Signed SSL Support**: Integrated `IOHttpClientAdapter` with `badCertificateCallback` on Dio so local/LAN Suwayomi servers handshake without SSL rejections.

---

### 🛡️ Universal Multi-Pass Self-Healing Image Loader
- **Anti-Hotlink Automatic Healing (Pass 2)**: Resolves `403 Forbidden` challenges across CDNs (e.g., ReadComicOnline, ImageKit, CloudFront) by dynamically dropping `Referer` headers on retry without requiring hardcoded source exceptions.
- **Same-Origin Referer Fallback (Pass 3)**: Recovers images from CDNs requiring same-origin domain `Referer` headers (e.g., Webtoons, Naver, Pixiv, MangaDex) when absent.
- **Clean Desktop Identity & Impersonation (Pass 4 & 5)**: Chrome desktop user-agent fallback and desktop TLS fingerprint impersonation for Cloudflare-protected servers.
- **Resilient Reader Control Flow**: Isolated try-catch blocks for every recovery pass so initial network socket errors never bypass downstream self-healing passes.
- **Corrupt File Defense**: Validates image magic bytes (JPEG, PNG, WebP, GIF, BMP) before saving to disk, preventing HTML error pages from being treated as downloaded chapters.

---

### 🎨 Reader & Library Polish
- **Library "Downloaded" Filter & Search**: Fixed `is:downloaded` query token and category filter chips to filter by distinct manga IDs having verified downloaded chapters.
- **Root Gesture Protection**: Added `NeverScrollableScrollPhysics()` on root `PageView` to eliminate horizontal gesture conflicts with nested category chips on iPad and mobile.
- **Reader RTL Tap Zones & Mode Cycling**: Honored `_invertTaps` across RTL Manga and Webtoon reading modes; preserved page/scroll offset when switching reading modes; added clearance for the iOS home indicator bar (`bottom: 16 + bottomInset`).
- **Chronological Batch Downloads**: Unread chapters are sorted ascending by `chapterNumber` so "Download Next 5" downloads the next reading sequence instead of descending from latest releases.
- **Download Queue Retries**: One-tap "Retry" and "Dismiss" buttons per failed download task.
- **Calendar-Safe DST Streaks**: Switched reading streak calculations in Stats to date-only logic to prevent Daylight Saving Time boundary errors.
- **Dynamic App Version Display**: Settings now dynamically queries `PackageInfo.fromPlatform()`, displaying `v3.0.0-beta+22`.
