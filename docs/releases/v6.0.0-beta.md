## 🚀 Sunfire v6.0.0 Beta

### 🤖 Android 15 & 16 16KB Page Alignment & Modern Memory Engine
- **16KB Memory Page Size Alignment**: Fully updated native compilation and packaging configuration (`-DANDROID_SUPPORT_FLEXIBLE_PAGE_SIZES=ON`, `-Wl,-z,max-page-size=16384`, `packagingOptions.jniLibs.useLegacyPackaging = false`) ensuring 100% native stability on Android 15 and Android 16 preview devices.
- **Cronet & OkHttp Connection Multiplexing**: Optimized HTTP/2 and HTTP/3 connection pools with keep-alive socket reuse for high-throughput image tile downloading.
- **Predictive Back Navigation**: Native `enableOnBackInvokedCallback` support with smooth gesture exit transitions.

---

### 🍏 iOS & iPadOS System Integration & Hardware Controls
- **Hardware Volume Rocker Navigation**: Read comfortably without touching the screen using physical volume buttons to turn pages in Manga mode or scroll viewport steps in Webtoon mode.
- **Magic Keyboard & Trackpad Gestures**: Precision horizontal and vertical two-finger trackpad panning with `PointerScrollEvent` threshold detection for instant page flips.
- **Dynamic Sideload Insets**: Automatic safe area adjustments for LiveContainer, AltStore, TrollStore, and Scarlet sideload environments.
- **Apple Files Document Sharing**: Native iOS document sharing enabled (`UIFileSharingEnabled`, `LSSupportsOpeningDocumentsInPlace`) for direct local chapter backups and imports.

---

### 📖 Webtoon & Manga Reader Supercharged
- **Webtoon Hands-Free Auto-Scroll**: Smooth continuous scrolling with adjustable speed controls (0.5x to 5.0x), automatic pause on tap/interaction, bottom boundary clamping, and safety pause on chapter transitions.
- **Eye Comfort Sepia Mode**: Added a calibrated Sepia color matrix alongside Amber Night, Grayscale, and Inverted Dark filters for reduced eye strain during extended reading sessions.
- **Inverted Tap Zone Navigation**: Full mirroring support for 3-zone tap controls to suit left-handed or single-handed reading preferences.
- **Zero-Crash Multi-Chapter Scrubbing**: Dynamic attachment and extent guards on scrubber slider; explicit cleanup of image buffers across chapters preventing Out-of-Memory crashes.
- **Interactive Page Recovery Capsule**: Tap-to-retry capsule on broken images allowing single-page progressive self-healing without reloading the whole chapter.

---

### 📚 Library & Browsing Improvements
- **Quick Status Filter Chips**: Filter your library instantly by reading state: *All*, *Unread*, *In Progress*, *Completed*, and *Downloaded*.
- **Liquid Glass Sidebar v6**: Refined responsive navigation rail with updated `v6.0 BETA` glass pill badge.
- **Instant Cross-Screen Synchronization**: Automatic local data reload when returning from reader to Manga Detail, History, and Updates screens.

---

### ⚡ Engine & Extension Hardening (Sunfire + Mangayomi Extensions)
- **QuickJS Isolated Lifecycle**: Clean sandboxed runtime teardown eliminating internal bridge `reference leak` diagnostic prints during engine disposal.
- **Safe Database Initialization Guard**: Guarded Isar database queries with `_isInitialized` checks, eliminating premature query exceptions on app launch.
- **Scraper Hardening**: Fully verified and hardened parsing logic, CDN Referer/Origin headers, and Cloudflare clearance cookie forwarding across Mangago, MangaPill, Webtoons, WeebCentral, MangaFreak, MangaHere, nHentai, and ReadComicOnline.
- **Offline Server Down Resilience**: Seamless fallback to cached local chapters and metadata when Suwayomi or FlareSolverr servers are temporarily offline.
