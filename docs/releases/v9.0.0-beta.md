# Sunfire v9.0.0-beta Release Notes

## 🚀 Overview
**Sunfire v9.0.0-beta** delivers comprehensive system hardening across the updates pipeline, reading history timeline, local chapter indexing, category persistence, library sorting uniformity, iPad download monitoring, and reader lifecycle observation. This release permanently eliminates back-chapter flooding in the Updates feed, ensures reading history purity, resolves unique index collisions for local titles, provides complete download queue visibility across all iPad layout modes, standardizes sorting directions, and enables full standalone category management.

---

## 🔑 Highlights & Key Improvements

### 1. 🛡️ Updates Feed Hardening & Anti-Flooding Engine
- **In-Place Chapter State Merging**: `MangaDetailScreen` (both Suwayomi GraphQL and local QuickJS scrapers) now cleanly merges incoming chapters with existing Isar records rather than wiping them.
  - **Preserved Chapter State**: Preserves existing `id`, `fetchedAt`, `isDownloadedLocally`, `localPath`, `isBookmarked`, and read progression.
  - **Authentic `fetchedAt` Protection**: Existing chapters retain their authentic discovery timestamp and are never overwritten with bulk server/scraper timestamps when reading or opening a series.
  - **New Chapter Delta Detection**: Only genuinely new chapters discovered on existing library titles (`existingChapters.isNotEmpty && inLibrary == true`) receive a fresh `fetchedAt` timestamp. Initial series additions default back-chapters to `fetchedAt = 0`.
- **Bulk Scrape / Server Dump Capping**:
  - `UpdatesScreen` limits incoming server chapters to at most **3 chapters per series** if a server response contains a bulk refresh/import (> 4 chapters for that title).
  - `IsarService.getRecentChapters()` enforces a maximum of 3 chapters per manga from the offline feed.
  - `cleanupBulkScrapedUpdates()` automatically identifies and cleans up legacy bulk dumps by bucketing timestamps into 60-second windows and keeping only the top 3 chapters.

### 2. 📖 Reading History Timeline Purity
- **Strict Timestamp Filtering**: `IsarService.getReadingHistory()` now queries chapters with `lastReadAtGreaterThan(0)` only.
- **Eliminated False "Today" Flooding**: Chapters imported from the server with `isRead = true` but without a timestamp (`lastReadAt == null || lastReadAt <= 0`) are safely excluded from the chronological History timeline, preventing hundreds of back-chapters from falsely displaying under "Today".

### 3. 🏷️ Category Management & Database Safety (Standalone & Server)
- **Safe Single-Category Saving**: Added `saveCategory(Category category)` in `IsarService`, preventing destructive wipeouts caused by array replacements.
- **Offline & Standalone Persistence**: Creating, renaming, and deleting categories now persists to the local Isar database even when disconnected, with primary key fallbacks in `deleteCategory`.
- **Suwayomi Batch Category Mutation Correction**: Replaced `updateMangaCategories` (`addToCategories`) with `setMangaCategories` (`patch: { categories: $categories }`) so unchecked categories are properly removed on the remote server.
- **Default Category Setting**: Added a configuration tile in **Settings > Library** allowing users to designate a default category. Automatically tags newly added manga in Isar and stamps `inLibraryAt`.
- **Direct Manga Details Category Picker**: Added `_showCategoryPickerDialog()` in `MangaDetailScreen`, accessible via a dedicated header button when in library and via long-press on the "IN LIBRARY" primary action button.

### 4. 🔄 Library Sorting Uniformity & Arrow Direction Resolution
- **Standardized Comparators**: Standardized all comparators to `cmp = a.compareTo(b)` across Title, Unread, Recent, and Chapters, ensuring `_isSortAscending ? cmp : -cmp` operates consistently.
- **Intuitive Default Directions**: Selecting `Title` defaults to Ascending (`A-Z`), while selecting `Unread`, `Recently Added`, or `Total Chapters` defaults to Descending (highest unread, newest added, most chapters first).

### 5. ⚡ Collision-Free Local Chapter ID Generation & Deterministic Ordering
- **Resolved `@Index(unique: true)` Replacement**: Fixed a critical bug in `library_update_service.dart` where local chapters with `manga.serverId <= 0` received `serverId = 0`, causing Isar to overwrite and delete previous chapters. Local chapters now use deterministic non-colliding IDs derived from `(mId.hashCode & 0x0007FFFF) * 1000 + index`.
- **Deterministic Secondary Tie-Breaking**: Added secondary sorting tie-breakers on `chapter.id`, ensuring stable ordering for chapters sharing duplicate chapter numbers (such as 0.0 specials or omake).
- **External Web Scheme Fallback**: Added automatic `https://` prefix fallback for domain-only URLs without explicit schemes in both reader and manga details.

### 6. 📱 iPad & Tablet Download Monitoring Parity
- **Dual-State Sidebar Access**:
  - **Expanded Sidebar**: `ACTIVITY > Downloads Queue` with real-time badge count.
  - **Collapsed Sidebar (Compact Rail)**: Dedicated 46x46 download icon with active task count badge in compact rail mode.
- **Settings Direct Access**: Added a prominent shortcut card at the top of **Settings > Downloads** allowing instant navigation to `/downloads`.
- **Context-Aware AppBar Controls**: Dynamically swaps queue controls based on active tab:
  - **Local Device Tab**: Pause/resume local queue, clear completed, cancel/retry.
  - **Suwayomi Server Tab**: Start/stop remote downloader, clear server queue, refresh server status.

### 7. 🎨 Appearance & Accent Color Expansion
- **Platform Separation**: Restricted Material You dynamic theming exclusively to Android 12+, removing invalid options on iPad and iOS.
- **Expanded Palette**: Introduced 16 curated theme accent colors (Catppuccin Blue, Emerald Green, Crimson Red, Amethyst Purple, Teal Cyan, Sakura Pink, Amber Gold, Nord Frost, Rose Pine, Lavender Mist, Cyber Lime, Sunset Coral, Midnight Indigo, Mocha Brown, Electric Violet, Sunfire Orange).

### 8. 🌐 FlareSolverr Custom Endpoint Configuration
- Added user-configurable FlareSolverr URL in Settings with live connectivity testing, removing hardcoded host URLs.
- Sanitized CDN referer headers and hardened QuickJS async engine bindings.
